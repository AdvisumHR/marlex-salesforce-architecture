# Marlex Salesforce Architecture

Client-facing architecture artifacts for the Marlex Group Salesforce programme,
published as a browsable site via GitHub Pages.

**Live site:** https://advisumhr.github.io/marlex-salesforce-architecture/

## Contents

| Section | What it is |

## Notes

- These pages are **narrative, client-facing** documents — written to be read
  without prior programme context.
- The site is **public**. Content is reviewed before publishing to ensure it
  carries no credentials, internal identifiers, cost or effort estimates, or
  other material not intended for external readers.
- Pages are generated from programme sources and republished here; this
  repository holds the published output.
